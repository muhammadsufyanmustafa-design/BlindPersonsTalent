Website changelog

A clear record of improvements made to the Blind Person’s Talent website.

Current release

Version 0.3 Beta

October 25, 2026

This release improves the embedded playlist experience, restores the complete organizational tagline in the site branding, and adds this changelog page.

Changes in Version 0.3 Beta

  1. Replaced the unreliable YouTube channel-handle embed with the official playlist ID supplied for the website.
  2. Added YouTube IFrame Player API integration to initialize the playlist player and request shuffle playback where supported.
  3. Added a clear fallback link to open the playlist directly on YouTube if the embedded player cannot load.
  4. Restored the complete tagline: “Blind Person’s Talent. Inspiring Humanity Through Ability Beyond Disability!”
  5. Added the Changelog page and linked it from the primary navigation.
  6. Updated the footer version label to Version 0.3 Beta.
  7. Retained the Skip to main content link, keyboard-accessible navigation, current-page indication, and descriptive player status messages.

Terms of Service and Privacy Policy are not included in this beta release. They are planned for a future version after their content has been provided and approved.

Version 0.2 Beta

Introduced the initial multi-page website structure, responsive layout, accessible navigation, About page, Our Work page, Latest Content page, Contact page, and not-found page.
